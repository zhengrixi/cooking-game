**Sunny Side Diner** — an original time-management cooking game for a desktop browser. Customers roll up to the counter with orders; you grill patties (don't let them burn), fry fries, stack burgers layer by layer in the exact order on the ticket, pour drinks and serve before patience runs out. Fast, accurate serves build a combo multiplier and bigger tips. Five days of service bring new recipes — the Garden Stack, the Double Trouble, the Tower — busier rushes and tighter patience. Hit each day's coin goal to earn your stars. Everything is drawn and sounded in code: no assets, no network, it plays fully offline from the static files in `game/`.

## Run it

```sh
node serve.ts        # then open http://localhost:8080 in a desktop browser
```

To hand the entry in the way the grader does, run `node main.ts` with `MAKEFUN_OUTPUT_DIR` set: it copies `game/` and `screenshots/` into the output directory and writes `dossier.json` there with the vendored make.fun library.
